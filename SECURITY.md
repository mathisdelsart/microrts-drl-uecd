# Security Policy

This repository ships a research artefact from a Master's thesis (UCLouvain).
It is not actively maintained as production software and does not carry
guarantees of any kind beyond the MIT license.

If you discover a security-relevant issue (e.g. a vulnerability in the Java↔Python
bridge, the JNI native code, the vendored dependencies, or any other component
shipped here), please **open a public GitHub issue** at
<https://github.com/mathisdelsart/microrts-drl-uecd/issues> describing the problem
and, if possible, a reproduction. There is no private disclosure channel; the
project's scope (academic, single-author, no production deployment) does not
warrant one. For sensitive cases that genuinely should not be public, email the
author directly: `mathis.delsart@gmail.com`.

Supported versions: only `main` (latest commit) is maintained.
