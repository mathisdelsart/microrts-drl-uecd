\chapter{Evaluation Map Visualizations}
\label{app:maps}

This appendix presents the initial game states of the twelve evaluation maps used in the benchmark tournament (Table~\ref{tab:evaluation-maps}): eight open maps (Figure~\ref{fig:all-open-maps}) and four closed maps (Figure~\ref{fig:all-closed-maps}). Maps are ordered by increasing grid size within each category. Visual conventions for units, resources, and terrain follow Section~\ref{sec:microrts_env}. All screenshots were captured from the MicroRTS game interface.
